PropDoc AI is an AI-powered document intelligence platform built with Python and Streamlit. It allows users to upload PDF documents, extract text using PyMuPDF and Tesseract OCR, analyze documents with OpenAI, ask questions about their content, and compare two documents to identify matching information, differences, missing details, and possible conflicts.

The application supports English, Marathi, and Hindi document processing and features a modern dark glassmorphism interface designed for a smooth and professional user experience.

**Key Features**
- 📄 PDF document upload and text extraction
- 🔍 OCR support for scanned and unclear documents
- 🌐 English, Marathi, and Hindi language support
- 🤖 AI-powered document analysis
- 💬 Ask questions about uploaded documents
- 🔄 Compare two PDF documents
- 📊 Identify differences, missing information, and possible conflicts
- 📥 Download extracted text and AI-generated reports
- 🔐 Secure OpenAI API configuration using Streamlit Secrets
- ☁️ Ready for deployment on Streamlit Community Cloud

**Technology Stack**
Python • Streamlit • OpenAI API • PyMuPDF • Tesseract OCR • Pillow
